# 3 Games Hub - Projet Développement Web L3 MIAGE

**Étudiant :** Aaron CABLING

## Description

Ce jeu s'inscrit dans le cadre du cours de développement web. J'ai fait ce projet seul.

## Parties qui m'ont posé le plus de difficulté

- **Le manque de communication** : C'est bien la seule chose que je reproche, avoir été prévenu 5 jours à l'avance que l'entièreté du projet était à rendre d'autant plus que j'avais posé des vacances étant alternant. Je pars du principe qu'aucun communiqué officiel n'a été donné, qu'aucunes autres consignes pour les deux derniers jeux n'ont été données, et que le dire dans un cours magistral sachant que nous n'avons plus eu de nouvelles pendant 3 mois n'est pas suffisant. Pour résoudre ce problème j'ai tout simplement énormément utilisé l'IA, pas forcément de la meilleure manière mais encore une fois, les délais m'ont forcé.

## Choix des jeux

- **Neon Pop** : C'est le jeu où j'ai pris le plus de plaisir à créer. En tant que premier jeu, je souhaitais un jeu simple, un peu addictif sur les bords et dans un thème un peu "néon", "rétro". J'ai donc pensé à un jeu rapide, pas compliqué à comprendre et l'idée de la réaction en chaîne m'est venue. Comme les consignes étaient claires et données à l'avance, j'ai pu prendre mon temps et paufiner chaque détail du jeu.

- **Le défi de l'Empereur** : Je voulais créer un jeu style "runner" comme un Subway Surfer/Temple Run avec le thème de l'Asie. Je me suis dit que je pourrais faire quelque chose dans le même style sur la muraille de Chine. Malheureusement pour des questions de temps je n'ai fait que le strict minimum, d'où le visuel très simple. Cependant, les mécaniques du jeu sont présentes.

- **Sticky Climber** : Pour ce jeu, j'ai eu l'inspiration directement de l'escalade car j'aime énormément ce sport. Je voulais au départ modéliser le grimpeur sous forme de Slime, avec de belles prises et surtout des mains. Pour des raisons encore une fois de temps, je n'ai pu que remplacer le slime humanoïde par un vrai blob, et changé le système de grimpe.
